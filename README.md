# AscendPulse · 极速成长系统

> 一个持续脉动式向上成长追踪系统。管理每日任务、习惯打卡、六维能力雷达与成就里程碑，把每一次成长量化成看得见的曲线。

## 为什么做这个

碎片化的目标管理工具往往只解决"记录"，不解决"动力"。AscendPulse 把成长拆成可累积的数值体系：**完成任务 → 获得成长点 → 升级 → 解锁称号与成就**，用游戏化的正向反馈维持行动节奏，同时用数据分析看清自己真实的成长轨迹。

## 功能特性

- **成长总览**：等级进度环、今日成长、连续打卡、累计成长点一屏总览；六维成长雷达 + 本周成长曲线实时绘制
- **每日任务**：按早晨 / 下午 / 晚上 / 夜间四个时段分组管理；完成加分（联动对应维度与等级经验），未完成在结算时扣分，形成闭环约束
- **习惯打卡**：每次打卡 +3 点，连续打卡天数（streak）会因中断重置，用"复利"逻辑培养稳定节律
- **六维成长**：学习 / 工作 / 健康 / 技能 / 社交 / 心智六个维度，任务自动加分，也可手动 ±5 记录
- **成就殿堂**：12 项里程碑自动检测解锁（连续打卡 3/7/30 天、累计 100/500/1000 点、六维共进等）
- **数据分析**：近 14 天成长趋势、时段活跃分布、每日明细表（获得 / 损失 / 净成长 / 结算状态），一键导出 Excel(CSV)
- **等级称号**：50 级成长曲线，10 档称号（启航者 → 进取者 → 破局者 → 攀登者 → 卓越者 → 领航者 → 远见者 → 变革者 → 巅峰者 → 永恒者）

## 快速开始

1. 下载 `index.html`，双击用浏览器打开即可使用，无需安装任何环境
2. 首次打开自动创建示例任务（6 个）与示例习惯（3 个），可直接使用或删改
3. 所有数据保存在本机浏览器 `localStorage`，关闭页面不丢失

## 使用建议

- 每天开始前看一眼"每日任务"，把重要事项排进对应时段
- 当天结束时点击右上角「结算今日」，未完成任务会自动按扣分值计入损失
- 每周到「数据分析」页导出一次 CSV 备份，追踪本周净成长
- 保持连续打卡，等级与称号会随积累自然晋升

## 数据与导出

| 项目 | 说明 |
|---|---|
| 存储位置 | 浏览器 localStorage（仅本机，不上传任何服务器） |
| 导出格式 | CSV（UTF-8 BOM，Excel 直接打开中文不乱码） |
| 导出内容 | 每日成长明细、任务清单、习惯打卡、六维成长、等级与累计点数 |
| 重置 | 「数据分析 → 数据管理 → 清空并重新开始」可一键重置 |

## 技术栈

- 纯原生 HTML / CSS / JavaScript，单文件自包含
- 图表全部 Canvas 手绘（等级环 / 六维雷达 / 成长曲线 / 时段分布），无第三方图表库
- 零外部 CDN 依赖，离线可运行
- 响应式适配：桌面侧边导航布局，移动端自动收窄为图标导航
